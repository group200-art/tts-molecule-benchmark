\section*{Limitations}
Each configuration has one recorded realization on two GeLLMO checkpoints. Budgets and property-tool access vary by method; seed variability and component effects remain unmeasured.

The original IND/OOD splits also differ in source filters. Quality averages condition on each method's successful subset. Reference groups depend on Mistral candidate pools. Output-token counts omit prompt processing, unreturned search work, and property computation, so total compute and latency remain unmeasured.

\section*{Ethical Considerations}
The study uses existing datasets and computational property predictions. Generated molecules lack experimental validation; optimizing the reported properties can overlook unmeasured toxicity.
