\section{Inference Methods}
\label{sec:methods}
We specify each method's molecular interface and output rule below; decoding parameters and scoring formulas are in Appendix~\ref{app:implementation}.

\paragraph{Beam search.}
Width-20 beam search returns model rank~0 \citep{beam2014}.

\paragraph{Repeated Sampling with verification.}
We generate 40 proposals and verify the first 20 in order \citep{repeatedsampling2024}. The verifier uses the success predicate from Section~\ref{sec:protocol}. We return the first passing proposal, or proposal~0 if none passes. Duplicates and invalid strings retain their positions. Thus, for the returned output $y^*$,
\begin{equation}
 S(x,y^*,T)=\max_{0\leq i<20}S(x,y_i,T).
 \label{eq:sampling-selection}
\end{equation}
Its single-output SR equals first-20 candidate coverage.

\paragraph{Self-Refine.}
We return the first revised molecule \citep{selfrefine2023}. Feedback comes from the same model and uses no external properties. The saved execution also includes feedback on the revised answer, counted in workload.

\paragraph{Tree of Thoughts.}
The generator model votes to retain three of five initial candidates, expands each retained candidate into five children, and votes for one final child \citep{tot2023}. Voting prompts contain no externally computed properties or validity labels.

\paragraph{Graph of Thoughts.}
GoT generates 12 initial nodes, then refines, merges, and aggregates selected parents, producing 28 nodes \citep{got2024}. A task-specific score combines property improvements, source similarity, SAS, and a duplicate penalty. It selects parents and returns the highest-scoring node in the completed graph.

\paragraph{s1 budget forcing.}
We use inference-time budget forcing without s1K training \citep{s1_2025}: greedy reasoning with a 512-token allowance and at most one \texttt{Wait} continuation, followed by a separate molecular answer.

\paragraph{Vote.}
We aggregate 400 proposals by molecular identity \citep{voting2024}. Valid outputs use canonical isomeric SMILES; invalid outputs use whitespace-normalized response text. The largest class wins, with ties resolved by first appearance; its earliest representative is returned.

\paragraph{Four-shot ICL.}
The contextual baseline uses four fixed training demonstrations and returns rank~0 from four-beam decoding \citep{brown2020}. Demonstration filtering excludes held-out combinations and evaluation-source identities.

\paragraph{Reflexion.}
We allow up to three trials, with evaluator feedback reporting binary success and invalid-output status \citep{reflexion2023}. Failed nonterminal trials trigger reflection; memory is confined to the current input. Execution stops on success or at the trial limit and returns the last action.
