\section{Benchmark Protocol}
\label{sec:protocol}
\subsection{Tasks and models}
We use frozen GeLLMO-P6 adapters on Mistral-7B-Instruct-v0.3 and Llama-3.1-8B-Instruct. All configurations share the original seen-instruction test manifests: five IND tasks with 2,500 task--input pairs and five OOD tasks with 1,405 pairs \citep{gellmo2025}. OOD refers to held-out property combinations. Table~\ref{tab:effectiveness} gives task definitions and sizes.

\subsection{Final-output evaluation}
Each method returns one molecule $y$ for source $x$ and target set $T$ ($K=1$). For a chemically valid, property-evaluable output, success is
\begin{equation}
 S(x,y,T)=\prod_{j\in T}\mathbf{1}\!\left[d_j(f_j(y)-f_j(x))>0\right],
\end{equation}
where $f_j$ is the fixed property evaluator and $d_j=-1$ for mutagenicity and $+1$ otherwise. Candidate values use the original two-decimal comparison conversion; source values retain their stored precision.

Empty, invalid, and documented non-evaluable outputs receive $S=0$ and remain in the denominator. Task success is $\mathrm{SR}_t=100\sum_i S_i/n_t$; the macro-average weights the ten task rates equally.

Methods retain their own output rules and internal budgets. Sampling, GoT, and Reflexion use property tools during inference; Table~\ref{tab:workload} records this access. The paired comparison contains 70,290 final outputs. Appendix~\ref{app:implementation} details evaluation precision, cache reuse, and decoding.
